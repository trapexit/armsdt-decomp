# Prompt templates

This directory contains reusable prompt templates for startup, handoff, and blocker triage.

Templates should reference canonical docs and skills rather than restating workflow authority.

Canonical authority remains in:

1. `decomp-docs/README.md`
2. `decomp-docs/workflow_manifest.json`
3. `decomp-docs/generic_step1.md`, `decomp-docs/generic_step2.md`, `decomp-docs/generic_step3.md`
4. Per-tool `decomp-docs/*_step*.md`
